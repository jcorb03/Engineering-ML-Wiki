# Welcome to Machine Learning for Engineers

This site aims to bridge the gap between engineering and machine learning by creating an open-source library of applied methods to real life practical problems.

Python implementations are currently only given due to it's widespread use in literature, however MATLAB code may be given in future.

## Commands

* `mkdocs new [dir-name]` - Create a new project.
* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.

## Project layout

    mkdocs.yml    # The configuration file.
    docs/
        index.md  # The documentation homepage.
        ...       # Other markdown pages, images and other files.
